# Rock-Sonar-Vs-Mine-Prediction

## Objective
The goal of this project is to build a machine learning system that can classify sonar signals as either coming from a **Rock** or a **Mine** . This is a binary classification problem focused on improving investigative accuracy in underwater environments.

## Tech Stack
* **Language:** Python
* **Libraries:** NumPy, Pandas, Sklearn (Logistic Regression)


## Results
The model was trained and evaluated using the Sonar dataset, achieving the following performance:
* **Training Data Accuracy:** 83.4%
* **Test Data Accuracy:** 76.2%
* **Outcome:** Successfully developed a predictive system that takes sonar frequency data and outputs a classification.

## Dataset
The dataset contains 60 features representing energy in specific frequency bands and one label column (R for Rock, M for Mine).
